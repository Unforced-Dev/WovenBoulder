East Boulder Sub-Community Plan and Form-Based Code

Land Use & Planning Implemented 1 meeting

Status: Implemented — FBC adopted; articulation standards work ongoing Lead Body: Planning Board Domain: Land Use and Zoning Last Seen: 2026-02

The East Boulder Sub-Community Plan and accompanying Form-Based Code (FBC) were developed to guide redevelopment of the East Boulder area. The FBC was adopted; subsequent work sessions addressed articulation standards and land use map amendments. An ongoing area of Planning Board activity.
